Method and limits

Both arms use suite {{ comparison.baseline.suite_name }}@{{ comparison.baseline.suite_version }} with hash {{ comparison.baseline.suite_definition_hash }}, provider {{ comparison.baseline.provider }}, and the same resilience policy and case/trial grid. An execution passes only when it completed, has at least one grader result, and every persisted criterion passed. Timing is synthetic infrastructure timing, not model latency. The fake provider records prompt identity but follows the same source-controlled typed plan for both prompts, so this report validates analysis plumbing and cannot establish that one prompt is better.
